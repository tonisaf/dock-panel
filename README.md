# Dock Panel

Выезжающая слева панель для Windows: лаунчер приложений + виджеты (погода, музыка, Notion, лимиты Claude/Codex).

Стек: Tauri 2 (Rust) · React 19 + TypeScript · Tailwind CSS 4 · Motion · Zustand · TanStack Query.

## Запуск

```bash
pnpm install
pnpm tauri dev
```

Панель открывается по **Ctrl+Space** (меняется в настройках) или кликом по иконке в трее. Закрывается по Esc, клику мимо или повторному сочетанию. Кнопка с булавкой справа от поиска закрепляет панель: она перестаёт прятаться при клике мимо, по Esc и после запуска приложений — до кнопки «Скрыть» рядом (или горячей клавиши). Вкладки: Ctrl+1…8.

В настройках: горячая клавиша, край экрана (слева/справа), ширина (1–3 колонки виджетов), тема (как в Windows / тёмная / светлая), акцентный цвет Windows.

Расстановка виджетов — кнопка ⚙ на главной: виджеты (включая «Закреплённые») перетаскиваются прямо по колонкам, глаз скрывает. Раскладка запоминается отдельно для 1, 2 и 3 колонок; «Авто» возвращает автоматическое распределение.

Spotify (нужен Premium): плей на плейлисте запускает музыку, даже если Spotify простаивает или закрыт; в «Сейчас играет» — перемотка кликом по полосе (для других плееров тоже, если они позволяют), перемешивание, повтор (плейлист / трек), громкость, список «Далее» (клик — перейти к треку), добавление текущего трека в свой плейлист, лайк и выбор устройства (Spotify Connect, он же в заголовке «Плейлисты»); в строке поиска `sp <запрос>` ищет в Spotify: Enter — играть, Shift+Enter — в очередь. Если вход в Spotify был до версии с лайками и плейлистами, для них нужно выйти и войти снова.

Виджет «Дом» управляет устройствами прямо по домашней сети, без облака: лампы Yeelight (вкл/выкл, яркость, температура, цвет; в приложении Yeelight у лампы должно быть включено «Управление по локальной сети») и колонки с Google Cast (что играет, пауза, треки, громкость). Найденные устройства запоминаются; ⟳ ищет заново.

Вкладка «Календарь» (Ctrl+5) — Google Календарь: окно плавно расширяется до недельной сетки. Режимы «День», «7 дней», «Месяц», «Расписание»; «Сегодня», ‹ › и стрелки ← →, номер недели, линия текущего времени. События можно перетаскивать на другое время и день, растягивать за нижний край, создавать протяжкой по пустому месту или кнопкой «Создать»; клик открывает карточку (подробности, «Присоединиться» для встреч, правка, удаление). Невыполненные задачи Google Tasks — строкой над сеткой, с отметкой «выполнено». Подключается в настройках своим OAuth-клиентом Google (тип Desktop app) с включёнными Calendar API и Tasks API.

Вкладка «Почта» (Ctrl+4): Яндекс, Gmail, Mail.ru, iCloud и другие ящики по IMAP с паролем приложения (добавляются в настройках). Входящие со всех ящиков (при прокрутке подгружаются более старые письма; при наведении на письмо — кнопки «в архив» и «удалить»; ↑/↓ — по списку, Enter — открыть), фильтр непрочитанных, чтение письма прямо в панели (окно плавно расширяется, письмо открывается справа от списка; границу между ними можно перетаскивать, двойной клик возвращает как было), архив, удаление, «непрочитанное», открытие в браузере. Счётчик непрочитанных на вкладке и на кнопке в панели задач (конверт рядом со значком панели, клик открывает почту), виджет «Почта» на главной и уведомления Windows о новых письмах (почта проверяется раз в минуту; клик по уведомлению открывает письмо).

Виджет «YouTube» — новые видео с ваших каналов по их RSS-лентам, без ключей и входа в Google. Каналы добавляются в настройках ссылкой, @именем или ссылкой на видео, либо импортом subscriptions.csv из Google Takeout. Клик открывает видео и отмечает его просмотренным; можно скрыть Shorts и включить уведомления о новых видео (ленты обновляются раз в 15 минут и кэшируются — без доступа к YouTube виджет показывает сохранённое). Если в панели выполнен вход в Google (раздел «Google Календарь», с включённым YouTube Data API v3), можно включить «Подписки из аккаунта Google»: каналы сами следуют за подписками (раз в час), а у видео появляются длительность и отметки «В эфире» / «Премьера» со временем начала.

Вкладка «Задачи»: клик по задаче открывает её карточку — название, статус, срок, приоритет и область меняются прямо в панели, там же удаление (в корзину Notion).

Вкладка «Заметки» (Ctrl+7) — заметки из базы Notion (выбирается в настройках Notion рядом с базой задач). Заметки со всем содержимым и картинками хранятся на компьютере: открываются и находятся поиском панели без интернета. Синхронизация раз в 5 минут и при открытии вкладки, заново скачиваются только изменённые. Из панели можно создавать и редактировать заметки: заголовок, теги, «закреплено» и текст. Текст правится в той же простой разметке («# » — заголовок, «- » — список, «1. » — нумерация, «[ ] » — чекбокс, «> » — цитата, Tab — вложить), а в Notion уходят только изменённые строки: нетронутые блоки сохраняют форматирование, картинки и код показаны строками ⟦…⟧ и остаются как есть. Без связи правки применяются к кэшу и ждут в очереди; прерванная отправка продолжается с того же места. Закреплённые — по флажку «Закреплено» (или Pinned) в базе, теги — из её multi-select.

Виджет «Discord» — через запущенный клиент Discord (локальный RPC) и своё приложение с discord.com/developers: кто сидит в выбранных голосовых каналах (уведомление, когда кто-то заходит; клик — зайти), микрофон, звук, режим рации, устройство ввода, глобальная горячая клавиша микрофона и индикатор микрофона на кнопке в панели задач, пока вы в голосовом канале.

Виджет «Помодоро» — фокус, перерыв и длинный перерыв; таймер идёт и при скрытой панели, в конце фазы — уведомление, оставшееся время — на кнопке в панели задач.

Закрепить можно не только приложение из списка, но и любой файл или папку: кнопками в заголовке «Закреплённые» (системный диалог) или перетащив их из Проводника на панель. Закреплённые файлы находятся поиском; в контекстном меню есть «Показать в папке».

Сборка установщика: `pnpm tauri build` → `src-tauri/target/release/bundle/nsis/Dock Panel_<версия>_x64-setup.exe` (ставится для текущего пользователя, без прав администратора). Иконки генерируются из `app-icon.svg`: `pnpm tauri icon app-icon.svg`.

## Устройство

- `src-tauri/src/panel.rs` — окно панели: позиция на мониторе с курсором, Acrylic, скругления, двухфазное скрытие (анимация во фронтенде, затем `hide_panel`).
- `src-tauri/src/tray.rs` — иконка в трее.
- `src-tauri/src/weather.rs` — погода и поиск города: Open-Meteo, а если он недоступен (в России без VPN), — MET Norway и OpenStreetMap Nominatim; ответы запасных сервисов переводятся в формат Open-Meteo в `src/widgets/weather/fallback.ts`.
- `src-tauri/src/home/` — «Дом»: протокол Yeelight (поиск по multicast, команды по TCP 55443) и Google Cast (mDNS, TLS 8009, protobuf).
- `src-tauri/src/mail/` — почта: `client.rs` — IMAP (соединение на ящик, список, чтение, действия), `mod.rs` — команды, хранение ящиков и фоновая проверка с уведомлениями.
- `src-tauri/src/youtube/` — YouTube: `parse.rs` — разбор RSS-лент, ссылок и Takeout CSV, `mod.rs` — каналы, загрузка лент с кэшем, фоновое обновление и уведомления.
- `src-tauri/src/gcal.rs` и `src/gcal/` — Google Календарь и Tasks (OAuth через `oauth.rs`, общий со Spotify).
- `src/shell/` — оболочка: анимация выезда, поиск, вкладки.
- `src/tabs/` — содержимое вкладок.
- `src-tauri/src/notes/` — заметки Notion: кэш на диске, синхронизация по `last_edited_time`, очередь офлайн-правок, поиск; `blocks.rs` — блоки Notion в упрощённое дерево.
- `src-tauri/src/discord/` — Discord RPC по named pipe (`ipc.rs` — кадры).
- `src-tauri/src/pomodoro.rs` — таймер помодоро.
