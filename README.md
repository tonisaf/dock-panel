# Dock Panel

Выезжающая слева панель для Windows: лаунчер приложений + виджеты (погода, музыка, Notion, лимиты Claude/Codex).

Стек: Tauri 2 (Rust) · React 19 + TypeScript · Tailwind CSS 4 · Motion · Zustand · TanStack Query.

## Выбор локальной модели и заметок

В настройках «Локальная LLM» можно выбрать LM Studio (127.0.0.1:1234) или Ollama (127.0.0.1:11434). Выбор действует на вкладку AI, краткий пересказ писем, брифинг, виджет и кнопку LLM. Для Ollama сначала установите модель через `ollama pull имя`; панель использует только установленные модели. Загрузку и выгрузку можно выполнять из панели. Остановка сервера доступна, если его запустила панель; Ollama, запущенную отдельно, остановите через её трей. Модели для кнопки LLM сохраняются отдельно для каждого провайдера.

В настройках «Заметки и задачи» выбирается Notion или Obsidian. Для Obsidian укажите существующую папку хранилища, затем сохраните выбор. Markdown-файлы доступны для чтения, поиска и редактирования текста. Новые заметки создаются в `Dock Panel/`, новые задачи — в `Dock Panel/Tasks.md`. Открытые задачи читаются из строк `- [ ]`, `* [ ]` и `+ [ ]` по всему хранилищу; чекбоксы в коде и YAML-метаданных пропускаются. Завершение, отмена, переименование задачи и удаление меняют только её строку. Переместившиеся или изменённые строки требуют обновления списка. Переименовывать файлы, работать с расширениями Obsidian и сложной Markdown-разметкой удобнее в Obsidian — есть кнопка открытия исходной заметки.

Заметки обновляются раз в 30 секунд при открытом представлении, задачи — раз в минуту; доступны кнопки обновления. Служебные скрытые папки пропускаются; ограничение — 5000 Markdown-файлов, 2 МБ на файл. При переключении существующие настройки и данные Notion сохраняются, автоматического переноса между источниками нет. По умолчанию остаются LM Studio и Notion.

## Запуск

```bash
pnpm install
pnpm tauri dev
```

Панель открывается по **Ctrl+Space** (меняется в настройках) или кликом по иконке в трее. Закрывается по Esc, клику мимо или повторному сочетанию. Кнопка с булавкой справа от поиска закрепляет панель: она перестаёт прятаться при клике мимо, по Esc и после запуска приложений — до кнопки «Скрыть» рядом (или горячей клавиши). Вкладки: Ctrl+1…8.

В настройках: горячая клавиша, край экрана (слева/справа), ширина (1–3 колонки виджетов), ширина самих виджетов (по умолчанию 500 px, в панели и на рабочем столе; панель при смене сохраняет число колонок), тема (как в Windows / тёмная / светлая), акцентный цвет Windows.

Расстановка виджетов — кнопка ⚙ на главной: виджеты (включая «Закреплённые») перетаскиваются прямо по колонкам, глаз скрывает. Раскладка запоминается отдельно для 1, 2 и 3 колонок; «Авто» возвращает автоматическое распределение.

Любой виджет можно вынести на рабочий стол: в расстановке (⚙) кнопка с монитором рядом с глазом. На рабочем столе виджет живёт в своём окне под всеми остальными окнами; зажать и подержать — перетащить (виджеты стоят по невидимой сетке, как в macOS: отпущенный виджет встаёт в ближайшую свободную ячейку и не налезает на соседей, а выросший сдвигает нижних), правый клик — «Открыть панель» или «Убрать с рабочего стола». Места запоминаются. Каждый такой виджет — отдельный WebView, так что это несколько десятков МБ памяти на виджет.

Spotify (нужен Premium): плей на плейлисте запускает музыку, даже если Spotify простаивает или закрыт; в «Сейчас играет» — перемотка кликом по полосе (для других плееров тоже, если они позволяют), перемешивание, повтор (плейлист / трек), громкость, список «Далее» (клик — перейти к треку), добавление текущего трека в свой плейлист, лайк и выбор устройства (Spotify Connect, он же в заголовке «Плейлисты»); в строке поиска `sp <запрос>` ищет в Spotify: Enter — играть, Shift+Enter — в очередь. Виджет «Моя музыка»: недавно сыгранное и топ треков и исполнителей (клик — играть), а вкладка «Статистика» — время, прослушивания, дни и часы, топ исполнителей и треков за 7/30/90 дней; её панель считает сама, пока Spotify играет на этом ПК, и хранит только локально. Если вход в Spotify был до версии с лайками, плейлистами или историей, для них нужно выйти и войти снова.

Виджет «Дом» управляет устройствами прямо по домашней сети, без облака: лампы Yeelight (вкл/выкл, яркость, температура, цвет; в приложении Yeelight у лампы должно быть включено «Управление по локальной сети») и колонки с Google Cast (что играет, пауза, треки, громкость). Найденные устройства запоминаются; ⟳ ищет заново.

Вкладка «Календарь» (Ctrl+5) — Google Календарь: окно плавно расширяется до недельной сетки. Режимы «День», «7 дней», «Месяц», «Расписание»; «Сегодня», ‹ › и стрелки ← →, номер недели, линия текущего времени. События можно перетаскивать на другое время и день, растягивать за нижний край, создавать протяжкой по пустому месту или кнопкой «Создать»; клик открывает карточку (подробности, «Присоединиться» для встреч, правка, удаление). Невыполненные задачи Google Tasks — строкой над сеткой, с отметкой «выполнено». Подключается в настройках своим OAuth-клиентом Google (тип Desktop app) с включёнными Calendar API и Tasks API.

Вкладка «Почта» (Ctrl+4): Яндекс, Gmail, Mail.ru, iCloud и другие ящики по IMAP с паролем приложения (добавляются в настройках). Входящие со всех ящиков (при прокрутке подгружаются более старые письма; при наведении на письмо — кнопки «в архив» и «удалить»; ↑/↓ — по списку, Enter — открыть), фильтр непрочитанных, чтение письма прямо в панели (окно плавно расширяется, письмо открывается справа от списка; границу между ними можно перетаскивать, двойной клик возвращает как было), архив, удаление, «непрочитанное», открытие в браузере. Счётчик непрочитанных на вкладке и на кнопке в панели задач (конверт рядом со значком панели, клик открывает почту), виджет «Почта» на главной и уведомления Windows о новых письмах (изменения приходят через IMAP IDLE по отдельному соединению, без блокировки чтения писем; если IDLE недоступен — проверка раз в минуту; клик по уведомлению открывает письмо).

Виджет «YouTube» — новые видео с ваших каналов по их RSS-лентам, без ключей и входа в Google. Каналы добавляются в настройках ссылкой, @именем или ссылкой на видео, либо импортом subscriptions.csv из Google Takeout. Клик открывает видео и отмечает его просмотренным; можно скрыть Shorts и включить уведомления о новых видео (ленты обновляются раз в 15 минут и кэшируются — без доступа к YouTube виджет показывает сохранённое). Если в панели выполнен вход в Google (раздел «Google Календарь», с включённым YouTube Data API v3), можно включить «Подписки из аккаунта Google»: каналы сами следуют за подписками (раз в час), а у видео появляются длительность и отметки «В эфире» / «Премьера» со временем начала.

Вкладка «Задачи»: клик по задаче открывает её карточку — название, статус, срок, приоритет и область меняются прямо в панели, там же удаление (в корзину Notion).

Вкладка «Заметки» (Ctrl+7) — заметки из базы Notion (выбирается в настройках Notion рядом с базой задач). Заметки со всем содержимым и картинками хранятся на компьютере: открываются и находятся поиском панели без интернета. Синхронизация раз в 5 минут и при открытии вкладки, заново скачиваются только изменённые. Из панели можно создавать и редактировать заметки: заголовок, теги, «закреплено» и текст. Текст правится в той же простой разметке («# » — заголовок, «- » — список, «1. » — нумерация, «[ ] » — чекбокс, «> » — цитата, Tab — вложить), а в Notion уходят только изменённые строки: нетронутые блоки сохраняют форматирование, картинки и код показаны строками ⟦…⟧ и остаются как есть. Без связи правки применяются к кэшу и ждут в очереди; прерванная отправка продолжается с того же места. Закреплённые — по флажку «Закреплено» (или Pinned) в базе, теги — из её multi-select.

Виджет «Discord» — через запущенный клиент Discord (локальный RPC) и своё приложение с discord.com/developers: кто сидит в выбранных голосовых каналах (уведомление, когда кто-то заходит; клик — зайти), микрофон, звук, режим рации, устройство ввода, глобальная горячая клавиша микрофона и индикатор микрофона на кнопке в панели задач, пока вы в голосовом канале.

Виджет «Docker» показывает контейнеры через `docker` из PATH (нужен Docker Desktop): запущенные сверху, остановленные в сворачиваемом списке, у каждого — образ, время работы, опубликованные порты, проект Compose и состояние health-check; кнопки «Запустить», «Остановить» и «Перезапустить». Контейнеры адресуются только по hex-id из `docker ps`, поэтому интерфейс не может передать в команду имя или опцию. Если Docker не запущен или не установлен, виджет пишет об этом.

Виджет «Помодоро» — фокус, перерыв и длинный перерыв; таймер идёт и при скрытой панели, в конце фазы — уведомление, оставшееся время — на кнопке в панели задач.

Вкладка «Приложения»: закреплённые переставляются перетаскиванием, а иконка, брошенная на другую, собирает папку (клик — открыть, название правится прямо в ней); «Часто используемые» учитывают и число запусков, и их свежесть; в «Всех приложениях» — быстрый переход по буквам. Правый клик: запуск от имени администратора, расположение файла, недавние файлы приложения (из списков переходов Windows — нужно включённое «Показывать недавно открытые элементы»), переименование, скрытие из списка (вернуть — в «Скрытых» внизу), удаление через параметры Windows.

Строка поиска кроме приложений находит заметки и файлы (свой индекс имён: домашняя папка без AppData и служебных папок вроде node_modules, плюс другие локальные диски; обновляется раз в 15 минут), считает («=2*(3+4)», «15% от 2400», «200 + 15%») и переводит валюты по курсу ЦБ («100 usd», «50 € в рублях»); Enter на ответе копирует его. Последняя строка — поиск в интернете (Google, Яндекс или DuckDuckGo, выбирается в настройках). Ctrl+Shift+Enter запускает приложение от имени администратора.

Закрепить можно не только приложение из списка, но и любой файл или папку: кнопками в заголовке «Закреплённые» (системный диалог) или перетащив их из Проводника на панель. Закреплённые файлы находятся поиском; в контекстном меню есть «Показать в папке».

Сборка установщика: `pnpm tauri build` → `src-tauri/target/release/bundle/nsis/Dock Panel_<версия>_x64-setup.exe` (ставится для текущего пользователя, без прав администратора). Иконки генерируются из `app-icon.svg`: `pnpm tauri icon app-icon.svg`.

## Проверки

CI (`.github/workflows/ci.yml`) на каждый PR и пуш в `main` собирает приложение на Windows и запускает:

- `pnpm test` и `pnpm build` (тесты и проверка типов фронтенда);
- `cargo clippy --locked --all-targets` — предупреждения показываются, но сборку не роняют;
- `cargo fmt --check` — форматирование Rust, падает при расхождениях;
- `cargo test --locked`.

Отдельная задача `audit` ищет известные уязвимости в `src-tauri/Cargo.lock` (`cargo audit`); запускается и по понедельникам, потому что новые advisory появляются без коммитов. Упавшей её делают только уязвимости, а предупреждения о неподдерживаемых или снятых крейтах — нет.

Те же проверки локально (Rust-часть собирается только на Windows):

```bash
pnpm test
cd src-tauri
cargo fmt          # перед коммитом; CI проверяет `cargo fmt --check`
cargo clippy --all-targets
cargo test
cargo install cargo-audit --locked   # один раз
cargo audit
```

Коммит с массовым форматированием скрыт из `git blame`: `git config blame.ignoreRevsFile .git-blame-ignore-revs`.

## Устройство

- `src-tauri/src/panel.rs` — окно панели: позиция на мониторе с курсором, Acrylic, скругления, двухфазное скрытие (анимация во фронтенде, затем `hide_panel`).
- `src-tauri/src/tray.rs` — иконка в трее.
- `src-tauri/src/trust.rs` — белый список запуска: `launch_app`, `launch_app_admin` и `open_recent` принимают только то, что выдал сам Rust (список приложений, диалог выбора, поиск файлов, недавние файлы, перетаскивание) или что закреплено в `prefs.json` на момент старта. Политика CSP задаётся в `src-tauri/tauri.conf.json`: новые источники картинок и сетевые запросы из интерфейса нужно разрешать там.
- `src-tauri/src/desktop.rs` и `src/desktop/` — виджеты на рабочем столе: окно на виджет (метка `desk-<id>`), всегда внизу по z-order и во владении рабочего стола.
- `src-tauri/src/weather.rs` — погода и поиск города: Open-Meteo, а если он недоступен (в России без VPN), — MET Norway и OpenStreetMap Nominatim; ответы запасных сервисов переводятся в формат Open-Meteo в `src/widgets/weather/fallback.ts`.
- `src-tauri/src/home/` — «Дом»: протокол Yeelight (поиск по multicast, команды по TCP 55443) и Google Cast (mDNS, TLS 8009, protobuf).
- `src-tauri/src/mail/` — почта: `client.rs` — IMAP (соединение на ящик, список, чтение, действия), `mod.rs` — команды, хранение ящиков и фоновая проверка с уведомлениями.
- `src-tauri/src/youtube/` — YouTube: `parse.rs` — разбор RSS-лент, ссылок и Takeout CSV, `mod.rs` — каналы, загрузка лент с кэшем, фоновое обновление и уведомления.
- `src-tauri/src/listening.rs` — локальная статистика прослушивания Spotify: раз в несколько секунд читает медиасессию Windows, копит время по дням, часам, исполнителям и трекам (`listening.json`, 90 дней); прослушивание засчитывается после 30 секунд, как у Spotify.
- `src-tauri/src/gcal.rs` и `src/gcal/` — Google Календарь и Tasks (OAuth через `oauth.rs`, общий со Spotify).
- `src/shell/` — оболочка: анимация выезда, поиск, вкладки.
- `src/tabs/` — содержимое вкладок.
- `src-tauri/src/notes/` — заметки Notion: кэш на диске, синхронизация по `last_edited_time`, очередь офлайн-правок, поиск; `blocks.rs` — блоки Notion в упрощённое дерево.
- `src-tauri/src/discord/` — Discord RPC по named pipe (`ipc.rs` — кадры).
- `src-tauri/src/pomodoro.rs` — таймер помодоро.

## Обновления и лицензия

Панель сама проверяет релизы на GitHub раз в 6 часов (Настройки → Обновления); обновления подписаны, публичный ключ лежит в `src-tauri/tauri.conf.json`. Обновления из публичного репозитория приходят без входа и токена GitHub. Сохранённый в старых версиях токен обновлений автоматически удаляется при запуске.

Лицензия — MIT, см. `LICENSE`.

### Собственный сервер уведомлений YouTube

По умолчанию используется опрос RSS раз в 15 минут. В настройках YouTube можно
выбрать собственный сервер WebSub, указать HTTPS-адрес и токен. При потере связи
сохраняется обычный опрос; при активных подписках контрольный опрос выполняется
раз в час. Токен хранится в Windows Credential Manager.

[Инструкция по развёртыванию контейнеров](server/youtube-push/README.md).

Поиск приложений исправляет русскую/английскую раскладку (`еу` → Telegram), понимает несколько слов в любом порядке (`vis code`, `code vis`) и смешанную раскладку (`мшы code`). Все слова запроса должны совпасть. Для близких результатов учитываются частота и давность успешного запуска из панели; точные совпадения сохраняют приоритет.


### Встроенные заметки Dock Panel

В настройках источника заметок выберите «Заметки Dock Panel» и сохраните выбор. На вкладке «Заметки» появится доска карточек: текст, списки с чекбоксами, закрепление и шесть вариантов цвета. Карточка открывается для редактирования, изменения автоматически сохраняются после паузы в наборе и перед закрытием. В случае ошибки запись остаётся локальным черновиком. Закреплённые карточки показаны отдельно, корзина позволяет восстановить заметку; автоматического удаления из корзины нет. Поиск внутри доски и общий поиск панели находят заголовки, текст и пункты списков. Заметка из выделенного текста Google AI также попадает сюда.

Хранилище — `local-notes.sqlite` в каталоге данных приложения (Tauri `app_data_dir`), SQLite с журналом WAL. Записи имеют постоянные ID и версии; устаревшая правка из другого окна не перезаписывает актуальную заметку. Данные существующих источников остаются на месте. Списки встроенных заметок не становятся задачами автоматически; при выборе встроенных заметок источник задач выбирается отдельно — Notion или Obsidian, предыдущий источник сохраняется. Метки, архив и перенос хранилища пока не реализованы.

Изображения во встроенных заметках: Ctrl+V в редакторе, перетаскивание файла из проводника на карточку или редактор, либо кнопка добавления изображения. Поддерживаются PNG, JPEG, GIF и WebP, до 20 МБ на файл и 20 изображений на заметку. Копии хранятся в `local-note-images` рядом с SQLite; одинаковые изображения не дублируются. Исходный файл после добавления не нужен. Удаление изображения из заметки убирает ссылку: сам файл сохраняется для других заметок, корзины и черновиков.
